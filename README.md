## Запуск проекта в Docker

## Перед запуском:

Убедитесь, что у вас установлены Docker и Docker Compose, python 3.11+ и pip. Вы можете установить их, следуя инструкциям на официальных страницах.

Запуск, миграции и загрузка тестовых данных будет выполнена автоматически.

### Стандартные команды

1. **Сборка и запуск контейнеров**:

   Чтобы собрать и запустить все сервисы, выполните:

   ```bash
   docker-compose up --build
   ```

2. **Остановка контейнеров**:

   Чтобы остановить и удалить контейнеры, выполните:

   ```bash
   docker-compose down --volumes
   

## Запуск из виртуальной среды

Убедитесь, что у вас установлен Python 3.12 и pip. Установите необходимые зависимости с помощью:
```bash
pip install -r requirements.txt
```
в settings.py измените настройки подключения для своей базы данных.

Проведите миграции 
```bash
python3 manage.py migrate
```
опционально: загрузите тестовые данные 
```bash
python3 manage.py load_sample_data
```
запуск сервера
```bash
python3 manage.py runserver
```

### также рекомендуется создать суперпользователя, для доступа к админ панкли, контроля и изменения данных.

запустите docker-compose с флагом -d

```bash
docker-compose up -d
```
выведите список процессов 

```bash
docker ps
```
найдите имя запущеного процесса приложения (образ change-web) и выполниет команду для запуска оболочки

```bash
docker exec -it <имя процесса> /bin/bash
```

далее выполните команды 

```bash
cd exchange
python3 manage.py createsuperuser
```
и следуйте указаниям...

чтобы выйти из оболочки выполните команду

```bash
exit
```



Доступ к панели по адресу:

http://localhost:8000/admin/




## Реализованные маршруты.

- **`маршрут`** — `представление`  

- **`/`** — `home`  
  Главная страница с полным списком объявлений. Есть фильтры по категории, состоянию и поиску.

- **`/login/`** — `login`  
  Страница для входа пользователя в систему.

- **`/logout/`** — `logout`  
  Выход пользователя из аккаунта.

- **`/register/`** — `register`  
  Форма регистрации нового пользователя.

- **`/item/<int:pk>/`** — `item_detail`  
  Детальная страница отдельного объявления с полным описанием.

- **`/my-items/`** — `my_items`  
  Список всех объявлений текущего пользователя. Можно редактировать и удалять.

- **`/item/create/`** — `create_item`  
  Создание нового объявления.

- **`/item/<int:pk>/edit/`** — `edit_item`  
  Редактирование существующего объявления пользователя.

- **`/item/delete/<int:pk>/`** — `delete_item`  
  Подтверждение и удаление объявления.

- **`/item/delete_proposal/<int:pk>/`** — `delete_proposal`  
  Удаление предложения обмена пользователя.

- **`/create_proposal/<int:pk_other>/`** — `create_proposal`  
  Выбор своего объявления для обмена с объявлением другого пользователя.

- **`/create_proposal/<int:pk_other>/<int:pk_my>/`** — `create_proposal_with_my_item`  
  Создание предложения обмена с выбранным своим объявлением (с комментарием).

- **`/exchange-proposals/`** — `exchange_proposals`  
  Отображение списка предложений обмена. Возможна фильтрация, сортировка, а также принятие и отклонение предложений (только для получателя).
